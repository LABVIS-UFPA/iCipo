    Como funciona a aba Artigos

    Esta aba concentra os artigos marcados para o projeto e permite revisar rapidamente os dados coletados.

    1
    Adicione artigos pelo navegadorNo Google Scholar, clique com o botão direito em um resultado, escolha “Marcar link” e selecione uma categoria.
    2
    Pesquise os artigosUse a busca para localizar títulos, autores, anos, tags e categorias.
    3
    Confira ano, categoria e resultadoA categoria registra o motivo detalhado; o sistema identifica duplicatas automaticamente pelo link.
    4
    Abra a fonte originalUse o botão da coluna Link para acessar a página do artigo e consultar o conteúdo completo.
    5
    Classifique vários artigos de uma vezSelecione os artigos pela caixa lateral e use “Incluir”, “Remover” ou “Pendente”. A ação aplica uma categoria ativa com o resultado correspondente e atualiza as métricas da fase.
    6
    Retire marcações quando necessárioUse “Remover marcados” apenas para retirar os registros da fase ativa. Essa ação é diferente de classificá-los como removidos da triagem.

    Tutorial · Etapa 2 de 4 Crie a primeira fase para continuar Este projeto ainda não possui fases. Preencha os campos obrigatórios e salve uma fase para liberar o dashboard.
    Controle da triagem: somente as categorias selecionadas aparecem no menu de marcação e somente os links classificados com elas são realçados no Scholar. Na fase seguinte, os artigos incluídos na fase anterior entram novamente como Pendentes. Pendente → fila da triagem · Incluído → selecionado para a próxima fase · Excluído → removido da progressão.
